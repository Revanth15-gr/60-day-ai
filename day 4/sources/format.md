# Day 4 — Sources Format

Use this file to describe the expected format for source files related to Day 4.

Recommended structure:

- `sources/` — place raw source files here (images, data, scripts)
- `format.md` — this template describing naming, encodings, and metadata

Naming conventions:
- Use lowercase with hyphens: `topic-subtopic.ext`
- Keep timestamps in ISO format when needed: `YYYY-MM-DD` or `YYYY-MM-DDTHHMM`

Metadata (optional):
- `author:` Your name
- `created:` YYYY-MM-DD
- `tags:` comma-separated tags

Example:
```
sources/problem-statement.md
sources/data/2026-07-11-dataset.csv
```

Replace this text with any project-specific formatting rules.
